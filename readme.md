# Título

O processo iniciou-se com a análise visual detalhada da obra original para mapear a grelha de linhas pretas e os blocos de cor. Foram tomadas decisões para garantir que a espessura das linhas e o posicionamento de cada quadrado/retângulo mantivessem o equilíbrio assimétrico característico do Neoplasticismo de Mondrian. Durante a programação, surgiu uma dificuldade técnica com a renderização das cores: os blocos estavam a trocar-se e a assumir cores erradas em cadeia. Após a análise, identificou-se que o problema residia no fluxo de leitura do código pelo p5.js. A solução final foi aplicar a função "fill()" imediatamente antes de desenhar cada respetivo "rect()". Compreendeu-se assim que o Git/p5.js executa as instruções sequencialmente, aplicando a última cor definida a tudo o que for desenhado a seguir. Sobre as linhas, estas também foram feitas tentativa a tentativa até descobrir qual a medida certa como na obra original, sendo uma das técnicas utilizar os números corretos que são mostrados na programação dos quadrados/retângulos.
